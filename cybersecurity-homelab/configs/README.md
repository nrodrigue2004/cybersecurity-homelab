# Configuration Notes

This directory contains concise, public-safe configuration documentation for the lab's core platforms. Live addresses, user names, node names, credentials, management URLs, exported configurations, and raw logs are intentionally excluded.

- [Kali Linux](kali/notes.md) — authorized testing workstation scope and administration practices.
- [pfSense](pfsense/notes.md) — segmentation, policy, and operational validation.
- [Proxmox](proxmox/notes.md) — virtualization topology and host administration.
- [Security Onion](security-onion/notes.md) — monitoring design and investigation practice.

Use placeholders when extending these notes. Store only safe example configurations in version control.
