# Detection and Hunting Notes

Use this directory for evidence-based detection hypotheses and hunting notes. Do not add raw PCAPs, log exports, screenshots with identifiers, or unredacted event data.

## Suggested record

- **Title and objective:** What behavior is being investigated?
- **Scope and authorization:** Which lab-owned systems and time window apply?
- **Data sources:** For example, Zeek, Suricata, endpoint logs, or firewall logs.
- **Hypothesis:** What telemetry would support or refute the question?
- **Method:** Queries, filters, or review steps, described at a safe high level.
- **Validation:** Controlled activity and expected evidence.
- **Findings and limitations:** Observed evidence, gaps, and next steps.

Only publish results that are supported by sanitized evidence.
