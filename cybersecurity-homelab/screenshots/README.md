# Screenshots

Add only sanitized screenshots that help explain a completed configuration, investigation, or walkthrough. Current repository screenshots are placeholders until redacted evidence is available.

Before publishing, remove or obscure:

- Public and private IP addresses, Tailscale addresses, MAC addresses, and management URLs.
- Usernames, hostnames, domains, device identifiers, and asset names.
- Passwords, tokens, session cookies, API keys, private keys, and QR codes.
- Log contents or packet details that could identify a person or live infrastructure.

Use descriptive file names and captions that explain the learning outcome rather than the live environment.
