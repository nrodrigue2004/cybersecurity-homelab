# Walkthroughs

This directory is reserved for sanitized, reproducible lab walkthroughs. Publish only activity that was performed against systems owned for this isolated environment.

## Walkthrough template

1. **Objective** — learning goal and expected outcome.
2. **Scope and authorization** — lab-owned assets only.
3. **Prerequisites** — safe setup steps and required telemetry.
4. **Method** — high-level procedure, without reusable unauthorized-access instructions.
5. **Expected telemetry** — logs, network evidence, or alerts to review.
6. **Findings** — documented observations and limitations.
7. **Cleanup** — reset actions, credential rotation if applicable, and verification.

Use screenshots only after removing addresses, hostnames, usernames, IDs, tokens, and personal information.
